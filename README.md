Resume + Job Match Analyzer

Project Description

The Resume + Job Match Analyzer is a Python-based web application that compares a candidate's resume with a job description. It identifies matching skills, missing skills, and the resume match percentage to help candidates improve their resumes.

Technologies Used

- Python
- Streamlit
- Natural Language Processing (NLP)
- PDF Text Extraction
- Scikit-learn

Features

- Upload resumes in PDF format.
- Enter a job description.
- Calculate the resume match percentage.
- Identify matching skills and missing skills.
- Suggest skills to learn or highlight.
- View extracted resume text.

How to Run the Project

1. Clone or download this repository.

2. Install the required packages:
   
   "pip install -r requirements.txt"

3. Run the application:
   
   "streamlit run app.py"

4. Open the local URL displayed in the terminal.

Project Structure

- "app.py" – Main application code.
- "requirements.txt" – Required Python packages.
- ".env" – Environment configuration, if required.

Expected Output

The application displays the resume match percentage, matching skills, missing skills, and suggestions based on the entered job description.

Conclusion

This project helps job seekers understand how well their resumes match job requirements and identify skills they may need to improve.
